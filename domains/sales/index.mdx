## Overview

The sales domain knows the customer and the deal. In the demo story, ACME's opportunity is
closed-won in Salesforce and order 4711 is created on 3 October.

## Business keys

`customerid`, `orderid`

## Services and events

Services and events of this domain appear here automatically as soon as their repository
releases a contract.

## Data model

Salesforce's own model, with Salesforce's naming (PascalCase, `__c` custom fields). The Salesforce System API translates the Order record to the order domain's contract; nobody else reads this model.
