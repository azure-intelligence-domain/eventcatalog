## Overview

The logistics domain knows the shipment. In the demo story, this is where order 4711 gets stuck:
after deployment v2.4 of the stock-to-3PL flow, the partner rejects the shipment request and it
ends up in the dead-letter queue.

## Business keys

`orderid`, `partnerid`, `customerid`

## Services and events

Services and events of this domain appear here automatically as soon as their repository
releases a contract.

## Data model

What the 3PL partner knows: the shipment of each order, and which version of the partner's API the mapping targets (the v2.4 story). Kept by the simulated partner speedy-3pl; the 3PL System API translates.
