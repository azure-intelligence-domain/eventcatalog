## Overview

The events half of the tap (<Link href="/docs/custom/platform/04-tap-by-default">tap by default</Link>).
The platform creates a `tap` subscription for all event types on every topic, so no producer
can forget it or opt out.

| Property | Value |
|---|---|
| Resource | `sttapintplatdemo`, resource group `rg-intplat-tap` (never deleted by the kill switch) |
| Retention | No expiry, until the Intelligence domain drains it (phase 2) |
| Limit | 64 KB per message; larger events go to the `tap-deadletter` container |
| Authentication | Entra ID only. Topics deliver with their own managed identity. |
