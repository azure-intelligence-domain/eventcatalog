## Overview

The telemetry half of the tap. Log Analytics exports these tables continuously into containers
named `am-<table>`:

`AppRequests` · `AppDependencies` · `AppExceptions` · `AppTraces` · `AegDeliveryFailureLogs` ·
`AegPublishFailureLogs` · `AZMSOperationalLogs`

Every request carries its `Correlation-Id`, so calls, events and deployments of the same journey
can be joined. Telemetry above the daily cap (0.15 GB) is neither ingested nor exported.
