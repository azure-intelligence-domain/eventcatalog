## Overview

The Event Grid custom topic of the Logistics domain: every business event the Logistics domain
publishes goes here, as a CloudEvent ([the envelope](/docs/custom/platform/01-the-envelope)).

| Property | Value |
|---|---|
| Resource | `evgt-intplat-logistics`, Belgium Central |
| Endpoint | `https://evgt-intplat-logistics.belgiumcentral-1.eventgrid.azure.net/api/events` |
| Schema | CloudEvents 1.0, structured mode |
| Authentication | Microsoft Entra ID only (local auth disabled). Producers need the EventGrid Data Sender role. |
| Delivery | One Event Grid subscription per consumer, delivering into that consumer's Service Bus queue |
| Diagnostics | Publish and delivery failures to Log Analytics |

Producers in the Logistics domain and the events they publish appear on the domain page as soon as
their contracts are released.
