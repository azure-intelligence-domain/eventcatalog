## Overview

The integration platform team owns everything every domain relies on: the event envelope (the one rule), the contract rules based on the adidas API guidelines, API Management, Event Grid and Service Bus, end-to-end tracing and the catalog. It does not own business logic.

Repositories in the [azure-intelligence-domain](https://github.com/azure-intelligence-domain) organisation.
